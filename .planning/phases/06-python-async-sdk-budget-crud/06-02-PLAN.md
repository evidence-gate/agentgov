**1b. Add `updateBudgetLimit()` to `ledger.ts`:**
- Add a new exported function after `settleHold`:
  ```typescript
  export async function updateBudgetLimit(
    db: DbClient,
    agentId: AgentId,
    limitUsd: number,
  ): Promise<typeof budgetLedger.$inferSelect | null> {
    const now = Date.now();
    const rows = await db
      .update(budgetLedger)
      .set({ limitUsd, updatedAt: now })  // ONLY limitUsd + updatedAt — NEVER spent_usd/reserved_usd
      .where(eq(budgetLedger.agentId, agentId))
      .returning();
    return rows[0] ?? null;
  }
  ```
- CRITICAL: The `.set()` call must ONLY include `limitUsd` and `updatedAt`. Never include `spentUsd` or `reservedUsd` — those are owned exclusively by Hold/Settle. Including them would race-write stale values and corrupt budget data.
- Do NOT wrap in a transaction — Turso HTTP client does not support interactive transactions.

- This is safe because both types are structurally identical (`ReturnType<typeof drizzle(client, { schema })>`). The Drizzle ORM operations are the same regardless of the underlying libsql transport.

- Add the PATCH endpoint BEFORE the `return router;` statement:
  ```typescript
  router.patch('/api/v1/dashboard/budgets/:agentId', async (c) => {
    const agentId = c.req.param('agentId');
    const body = await c.req.json<{ limitUsd: number }>();

    // Validate limitUsd
    if (typeof body.limitUsd !== 'number' || !isFinite(body.limitUsd) || body.limitUsd < 0) {
      return c.json({ error: { code: 'INVALID_LIMIT', message: 'limitUsd must be a non-negative finite number' } }, 400);
    }

    // Get current budget for audit log (previous value)
    const current = await getBudget(db, agentId as AgentId);

    const updated = await updateBudgetLimit(db, agentId as AgentId, body.limitUsd);
    if (!updated) {
      return c.json({ error: { code: 'AGENT_NOT_FOUND', message: `No budget row for agent: ${agentId}` } }, 404);
    }

    // BUDGET-02: Audit event — fire-and-forget (appendAuditEvent never throws)
    appendAuditEvent(db, {
      eventType: 'budget_limit_changed',
      agentId: agentId as AgentId,
      model: '',           // no model for admin operation — '' is acceptable for notNull column
      costDelta: 0,        // no cost impact
      runningBalance: 0,   // admin operation, not a cost event
      meta: {
        previousLimitUsd: current?.limitUsd ?? null,
        newLimitUsd: body.limitUsd,
      },
    }).catch(err => console.error('budget_limit_changed audit write failed:', err));

    return c.json(updated);
  });
  ```
- Also add import for `getBudget` from `'../budget/ledger'` (already may be available; check if it needs to be added to the import line).
- The audit `meta.previousLimitUsd` captures the value before the change for traceability per BUDGET-02.

**2a. Add `useUpdateBudgetLimit()` mutation hook to `useDashboard.ts`:**
- Add imports: `useMutation, useQueryClient` from `@tanstack/react-query`
- Add the mutation hook after the existing query hooks:
  ```typescript
  export function useUpdateBudgetLimit() {
    const queryClient = useQueryClient();
    return useMutation({
      mutationFn: ({ agentId, limitUsd }: { agentId: string; limitUsd: number }) =>
        fetch(`${API_BASE}/api/v1/dashboard/budgets/${encodeURIComponent(agentId)}`, {
          method: 'PATCH',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ limitUsd }),
        }).then(r => {
          if (!r.ok) throw new Error(`HTTP ${r.status}`);
          return r.json();
        }),
      onSuccess: () => {
        queryClient.invalidateQueries({ queryKey: ['budgets'] });
      },
    });
  }
  ```
- The `onSuccess` callback invalidates the budgets query cache, triggering an immediate refetch so the table shows the new value.
