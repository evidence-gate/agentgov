  - Response reconstruction: identical `httpx.Response(status_code=..., headers=..., content=content)`
  - `async def aclose(self) -> None:` calls `await self._inner.aclose()`

- ANTI-PATTERN: Do not subclass `httpx.BaseTransport` — httpx transport hierarchies are separate
