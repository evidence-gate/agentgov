**Step 2 — Create `.github/workflows/ci.yml`:**

Create the directory `.github/workflows/` first.

The workflow must:

1. **Trigger:** `on: push` (all branches) and `on: pull_request` (all branches)

2. **Job: lint** (runs on `ubuntu-latest`, Node.js 20)
   - Checkout code
   - Install pnpm via `corepack enable` (pnpm@10 is declared in packageManager field)
   - Run `pnpm install --frozen-lockfile`
   - Run `pnpm --filter @agentgov/proxy lint`
   - Run `pnpm --filter @agentgov/sdk lint`
   - Run `pnpm --filter @agentgov/dashboard lint`

3. **Job: test-node** (runs on `ubuntu-latest`, Node.js 20)
   - Checkout code
   - Install pnpm via `corepack enable`
   - Run `pnpm install --frozen-lockfile`
   - Run `pnpm --filter @agentgov/proxy test:node` (the 148 Node.js vitest tests — uses vitest.config.node.ts)
   - Run `pnpm --filter @agentgov/sdk test` (SDK vitest tests)

4. **Job: test-workers** (runs on `ubuntu-latest`, Node.js 20)
   - Checkout code
   - Install pnpm via `corepack enable`
   - Run `pnpm install --frozen-lockfile`
   - Run `pnpm --filter @agentgov/proxy test:workers` (the 24 Workers pool vitest tests — requires workerd via @cloudflare/vitest-pool-workers)

5. **Job: test-python** (runs on `ubuntu-latest`, Python 3.11)
   - Checkout code
   - Set up Python 3.11 with `actions/setup-python@v5`
   - `cd packages/sdk-python && pip install -e ".[dev,openai,anthropic]" && pytest tests/ -v`

Design notes:
- Split tests into 3 parallel jobs (test-node, test-workers, test-python) for faster feedback. Lint runs in parallel too.
- Use `corepack enable` instead of `pnpm/action-setup` — corepack is built into Node.js 20 and reads the `packageManager` field directly.
- Do NOT use matrix strategy — the 4 jobs have different runtimes and commands.
- Pin `actions/checkout@v4`, `actions/setup-node@v4`, `actions/setup-python@v5`.
- Add `concurrency` group to cancel in-progress runs when new commits are pushed to the same branch/PR.
