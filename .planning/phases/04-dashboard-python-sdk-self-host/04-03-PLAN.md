  <action>
    1. **package.json**: Name `@agentgov/dashboard`, private: true. Dependencies: react@19, react-dom@19, @tanstack/react-query@^5. DevDependencies: vite@^6, @vitejs/plugin-react, typescript, @types/react, @types/react-dom. Scripts: `"dev": "vite"`, `"build": "vite build"`, `"preview": "vite preview"`.

       Install: `cd packages/dashboard && pnpm install`

    2. **tsconfig.json**: target ES2022, module ESNext, moduleResolution bundler, jsx react-jsx, strict true, include ["src"].

    3. **vite.config.ts**: React plugin. Dev server proxy: `'/api': { target: 'http://localhost:8787', changeOrigin: true }` so API calls during dev go to the proxy running locally. Build output to `dist/`.

    4. **index.html**: Standard Vite SPA entry: `<div id="root"></div>`, script tag pointing to `/src/main.tsx`.

    5. **main.tsx**: React 19 createRoot, wrap App in QueryClientProvider from @tanstack/react-query.

    6. **App.tsx**: Simple tab/nav layout with three sections: Costs, Approvals, Audit. Use basic state-based tab switching (no React Router needed for 3 tabs). Render the corresponding page component based on active tab. Minimal styling with inline styles or a small CSS file -- keep it functional, not beautiful. MVP dashboard.

    7. **hooks/useDashboard.ts**: Three TanStack Query hooks:
       - `useBudgets()`: queryKey ['budgets'], fetches `/api/v1/dashboard/budgets`, refetchInterval: 5000, staleTime: 3000
       - `useAuditLog(limit = 100)`: queryKey ['audit', limit], fetches `/api/v1/dashboard/audit?limit=${limit}`, refetchInterval: 5000
       - `usePendingApprovals()`: queryKey ['approvals'], fetches `/api/v1/dashboard/approvals`, refetchInterval: 5000

       Each hook returns the standard useQuery result (data, isLoading, error). The `API_BASE` should use `import.meta.env.VITE_API_URL ?? ''` (empty string defaults to same-origin, which works for both dev proxy and Docker serving).
  </action>

  <action>
    1. **costs.tsx**: Budget summary page.
       - Uses `useBudgets()` hook
       - Renders a table with columns: Agent ID, Limit (USD), Spent (USD), Reserved (USD), Available (USD = limit - spent - reserved), Last Updated
       - Shows loading state and error state
       - Format USD values to 4 decimal places
       - Format timestamps to locale date string
       - If no budgets exist, show "No budgets configured" message

    2. **approvals.tsx**: HITL approval queue page.
       - Uses `usePendingApprovals()` hook
       - Renders a table with columns: Approval ID (truncated UUID), Agent ID, Action, Risk Tier, Created, Expires
       - Risk tier displayed with color coding: irreversible=red, semi-reversible=orange, reversible=green, external=purple (inline styles)
       - Shows "No pending approvals" if empty
       - NOTE: This is read-only. No approve/deny buttons. Dashboard has no write path per design constraint.

    3. **audit.tsx**: Audit log page.
       - Uses `useAuditLog(100)` hook
       - Renders a table with columns: Seq, Event Type, Agent ID, Model, Cost Delta, Running Balance, Timestamp
       - Event type displayed as badge/tag (inline styles, different background per type)
       - Cost delta formatted to 4 decimal places with +/- sign
       - Shows most recent events first (API returns DESC order)
       - Shows "No audit events" if empty

    All three pages: minimal functional styling (no CSS framework). Tables with basic borders, padding, alternating row colors via inline styles. Header with page title. The goal is functional readability, not visual polish.

    IMPORTANT: No chart library. Text tables are sufficient for MVP per research recommendation.
