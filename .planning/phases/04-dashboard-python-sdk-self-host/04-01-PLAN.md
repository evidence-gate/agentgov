<!-- TypeScript SDK error shapes — Python exceptions MUST match these fields exactly -->

From packages/sdk-typescript/src/errors.ts:
```typescript
class BudgetExceeded extends Error {
  readonly code = 'BUDGET_EXCEEDED'
  readonly spent: number      // USD
  readonly limit: number      // USD
  readonly budgetId: string   // agent ID
}

class HitlPending extends Error {
  readonly code = 'HITL_PENDING'
  readonly approvalId: string
  readonly agentId: string
  readonly expiresAt: number  // Unix ms
}

class AgentError extends Error {
  readonly code = 'AGENT_ERROR'
  readonly type: 'retry_exhausted' | 'permanent_error' | 'stuck_detected'
  readonly agentId: string
  readonly timestamp: number
  readonly suggestedRemediation: string
  readonly context?: Record<string, unknown>
}
```

HTTP contract (proxy responses that trigger exceptions):
- 429 + `{ error: { code: 'BUDGET_EXCEEDED', message, budgetId, spent, limit } }` -> BudgetExceeded
- 202 + `{ error: { code: 'HITL_PENDING', message, approvalId, agentId, expiresAt } }` -> HitlPending
- 502 + `{ error: { code: 'AGENT_ERROR', message, type, agentId, timestamp, suggestedRemediation, context? } }` -> AgentError

Call wrapped transport. Inspect response: read and check status code + error code for governance exceptions. CRITICAL: Use `response.read()` to load body, then check — for non-matching status codes, return a new `httpx.Response` with the already-read content (since stream is consumed).
       - `close(self)`: Close wrapped transport.
       - For 429: parse JSON, if `error.code == 'BUDGET_EXCEEDED'` raise `BudgetExceeded(error_dict)`, else return response.

       - For 502: parse JSON, if `error.code == 'AGENT_ERROR'` raise `AgentError(error_dict)`, else return response.

       - Sets `client._client = http_client` (both OpenAI and Anthropic store the httpx.Client as `_client`)
       - Returns the mutated client
       - NOTE: This uses private attribute mutation. Document that users can alternatively construct their client with `http_client=` parameter directly. Per research, this is the pragmatic approach for `wrap()` — post-construction patching.
