  <action>
    **1. Create slack.ts** — `verifySlackSignature(request: Request, rawBody: string, signingSecret: string): Promise<boolean>`:
    - Uses `crypto.subtle` (same Web Crypto API as audit/writer.ts `sha256Hex`)
    - Base string: `v0:${timestamp}:${rawBody}` where timestamp = `X-Slack-Request-Timestamp` header
    - Replay prevention: reject if `|Date.now()/1000 - parseInt(timestamp)| > 300`
    - HMAC-SHA256 with `crypto.subtle.importKey('raw', ..., { name: 'HMAC', hash: 'SHA-256' })` then `crypto.subtle.sign('HMAC', ...)`
    - Constant-time comparison: XOR each charCode, check result === 0
    - Returns false (not throws) on any failure

    **2. Create routes.ts** — Export a Hono sub-app or route group `hitlRoutes`:
    ```typescript
    import { Hono } from 'hono';

    ```

    **Approve endpoint: `POST /v1/hitl/:id/approve`**
    - Parse JSON body: `{ actor: string, reason?: string }`
    - Get workflow instance: `c.env.HITL_WORKFLOW.get(ticketId)`
    - Call `instance.sendEvent({ type: 'hitl-decision', payload: { decision: 'approved', actor, reason } })`
    - Return `c.json({ ok: true })` 200
    - If workflow instance not found, return 404

    **Deny endpoint: `POST /v1/hitl/:id/deny`**
    - Same pattern as approve but `decision: 'denied'`

    **Status endpoint: `GET /v1/hitl/:id/status`**
    - Create DB client from env
    - Call `getTicket(db, ticketId)`
    - If ticket found, return `c.json({ id, status, riskTier, actionName, approver, createdAt, expiresAt, decidedAt })` 200
    - If not found, return 404

    **Slack callback: `POST /v1/slack/callback`**
    - Read raw body ONCE: `const rawBody = await c.req.text()`
    - Verify signature: `verifySlackSignature(c.req.raw, rawBody, c.env.SLACK_SIGNING_SECRET)` — if false return 401
    - Parse: `new URLSearchParams(rawBody).get('payload')` then `JSON.parse(payload)`
    - Extract: `actions[0].action_id` ('approve'|'deny'), `actions[0].value` (ticketId), `user.username` (actor)
    - Push actual work to `executionCtx.waitUntil()` (per Slack 3-second constraint, per research Pitfall 5):

      ```typescript
          payload: { decision: actionId === 'approve' ? 'approved' : 'denied', actor },
        });
      })();
      if (c.executionCtx?.waitUntil) c.executionCtx.waitUntil(workPromise);
      ```
    - Return `c.json({ ok: true })` immediately

    **1. Update index.ts — Add HITL classification between budget gate and forwardToLlm:**

    After `budgetGate` passes (Step 4) and before `forwardToLlm` (Step 5), add new Step 4.5:

    ```typescript
    // Step 4.5: HITL action classification
    // Check if any tool_calls in the request require human approval
    const toolCalls = extractToolCalls(body);
    if (toolCalls.length > 0) {
      const hitlResult = classifyToolCalls(toolCalls);
      if (hitlResult.required) {
        // Trigger HITL workflow — agent must pause
        const ticketId = crypto.randomUUID();
        const ttlSeconds = parseInt(c.env?.AGENTGOV_HITL_TTL_SECONDS ?? '259200', 10);
        const expiresAt = Date.now() + (ttlSeconds * 1000);
        const callbackBaseUrl = new URL(c.req.url).origin;

        // Create Workflow instance (uses ticketId as instance ID per research Pitfall 1)
        await c.env.HITL_WORKFLOW.create({
          id: ticketId,
          params: {
            ticketId,
            agentId,
            actionName: hitlResult.actionName,
            riskTier: hitlResult.tier,
            requestPayload: JSON.stringify(body),
            ttlSeconds,
            holdId,
            callbackBaseUrl,
            webhookUrl: c.env?.AGENTGOV_HITL_WEBHOOK_URL || undefined,
            slackBotToken: c.env?.SLACK_BOT_TOKEN || undefined,
            slackChannelId: c.env?.SLACK_CHANNEL_ID || undefined,
          },
        });

        // Return 202 Accepted — agent should pause
        return c.json({
          error: {
            code: 'HITL_PENDING',
            message: `Action '${hitlResult.actionName}' requires human approval. Use approvalId to poll status.`,
            approvalId: ticketId,
            agentId,
            expiresAt,
          },
        }, 202);
      }
    }
    // If no HITL required, continue to Step 5: forwardToLlm
    ```

    **Helper function `classifyToolCalls`:** Run `classifyAction` on each extracted tool_call name. Return `{ required: true, tier, actionName }` for the FIRST action requiring HITL (highest-risk-first), or `{ required: false }` if none require it.
